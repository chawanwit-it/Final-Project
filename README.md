# ระบบเยี่ยมบ้านออนไลน์ (Online Home Visit System)

## เกี่ยวกับโปรเจกต์

เว็บแอปพลิเคชันสำหรับจัดการข้อมูลนักเรียนและการเยี่ยมบ้านของสถานศึกษา ช่วยให้ครูและบุคลากรสามารถจัดเก็บข้อมูลนักเรียน ข้อมูลครอบครัว บันทึกผลการเยี่ยมบ้าน และติดตามสถานะการดำเนินงานผ่านระบบออนไลน์

โปรเจกต์นี้เป็นส่วนหนึ่งของโครงงานจบการศึกษา พัฒนาด้วยเทคโนโลยีเว็บแอปพลิเคชันและฐานข้อมูล เพื่อให้สามารถนำไปศึกษาและต่อยอดพัฒนาระบบเพิ่มเติมได้

## เทคโนโลยีที่ใช้

- Frontend: Nuxt.js, Vue.js, Vuetify
- Backend: Node.js, Express.js
- Database: MySQL
- Database Management: phpMyAdmin
- Containerization: Docker
- HTTP Client: Axios
- Query Builder: Knex.js

## ฟังก์ชันหลัก

- ระบบเข้าสู่ระบบและกำหนดสิทธิ์ผู้ใช้งาน
- จัดการข้อมูลนักเรียนและครอบครัว
- จัดการข้อมูลครูและที่ปรึกษา
- บันทึกผลและติดตามสถานะการเยี่ยมบ้าน
- อัปโหลดรูปภาพประกอบการเยี่ยมบ้าน
- จัดการข้อมูลภาคเรียน
- เรียกดูและจัดทำรายงานการเยี่ยมบ้าน

## สิ่งที่ต้องติดตั้งก่อนใช้งาน

1. Git — สำหรับดาวน์โหลดซอร์สโค้ด
2. Node.js และ npm — สำหรับติดตั้ง Dependencies และรัน Frontend/Backend
3. Docker Desktop — สำหรับเปิดใช้งานบริการฐานข้อมูลและ phpMyAdmin ตามการตั้งค่าของผู้ใช้

## วิธีติดตั้งและเริ่มต้นใช้งาน

### 1. ดาวน์โหลดโปรเจกต์

เปิด Terminal หรือ Command Prompt แล้วใช้คำสั่ง
```
git clone https://github.com/chawanwit-it/project-jr.git
cd project-jr
```

หากไม่มี Git สามารถดาวน์โหลดโปรเจกต์จากปุ่ม Code → Download ZIP บน GitHub ได้เช่นกัน

### 2. ตรวจสอบโครงสร้างโปรเจกต์
```
dir
dir server
dir app-nuxt
dir app
dir my-app
```

ตรวจสอบไฟล์ `package.json` ในแต่ละโฟลเดอร์ เพื่อระบุว่าโฟลเดอร์ใดเป็น Frontend ตัวหลักและโฟลเดอร์ใดเป็น Backend

### 3. เริ่มต้น Docker

โปรเจกต์มีไฟล์ `docker-compose.yml` กำหนดบริการ MySQL และ phpMyAdmin ไว้ให้แล้ว สามารถเริ่มใช้งานได้ทันทีในโฟลเดอร์ที่มีไฟล์ดังกล่าว

ตรวจสอบว่าติดตั้ง Docker เรียบร้อย:
```
docker --version
docker compose version
```

เริ่มบริการ:
```
docker compose up -d
```

หากต้องการสร้าง Image ใหม่และเริ่มบริการ:
```
docker compose up -d --build
```

ตรวจสอบสถานะบริการ:
```
docker compose ps
docker compose logs
```

### 4. จัดการฐานข้อมูลผ่าน phpMyAdmin

เปิดเว็บเบราว์เซอร์และเข้า URL
```
http://localhost:8080
```

จากนั้นดำเนินการดังนี้

1. เข้าสู่ระบบ phpMyAdmin ด้วยข้อมูลที่ตั้งค่าไว้
2. เลือกหรือสร้างฐานข้อมูล `school_management`
3. เลือกเมนู Import
4. เลือกไฟล์ SQL ของโปรเจกต์
5. กด Import และรอจนเสร็จ
6. ตรวจสอบว่าตารางฐานข้อมูลถูกสร้างเรียบร้อย

### 5. ตั้งค่าการเชื่อมต่อฐานข้อมูล

สร้างหรือตรวจสอบไฟล์ `.env` ในโฟลเดอร์ Backend ให้มีค่าดังนี้
```dotenv
DB_HOST=127.0.0.1
DB_USER=root
DB_PASSWORD=rootpass
DB_NAME=school_management
DB_PORT=3306
PORT=7000
JWT_SECRET=your_jwt_secret_key
```

ห้ามเผยแพร่รหัสผ่านจริงหรือไฟล์ `.env` ที่มีข้อมูลสำคัญขึ้น GitHub

### 6. ติดตั้ง Dependencies ของ Backend

เข้าโฟลเดอร์ Backend ที่มีไฟล์ `package.json`
```
cd server
npm install
```

ตรวจสอบคำสั่งที่มีอยู่ใน `package.json`:
```
npm run
```

หากมีคำสั่ง `dev` ให้เริ่มระบบด้วย
```
npm run dev
```

หากมีคำสั่ง `start` ให้ใช้
```
npm start
```

คำสั่งที่ใช้งานได้จริงขึ้นอยู่กับ `scripts` ที่กำหนดไว้ใน `package.json`

### 7. ติดตั้ง Dependencies ของ Frontend

เปิด Terminal ใหม่ แล้วเข้าโฟลเดอร์ Frontend ตัวหลักที่มีไฟล์ `package.json` เช่น `app-nuxt`
```
cd app-nuxt
npm install
npm run dev
```

หากเป็น Nuxt ที่ตั้งค่าตามปกติ สามารถเปิดเว็บไซต์ได้ที่
```
http://localhost:3000
```

หาก Frontend ตัวหลักอยู่ในโฟลเดอร์อื่น ให้เปลี่ยนไปใช้โฟลเดอร์นั้นแทน

### 8. ทดสอบการทำงาน

หลังจากเปิดบริการครบแล้ว ให้ตรวจสอบว่า

- Docker และ MySQL ทำงานปกติ
- phpMyAdmin สามารถเข้าถึงฐานข้อมูลได้
- Backend เชื่อมต่อฐานข้อมูลสำเร็จ
- Frontend เปิดหน้าเว็บไซต์ได้
- ระบบเข้าสู่ระบบและเรียก API ได้
- สามารถทดลองเรียกดูข้อมูลและบันทึกข้อมูลได้

## แนวทางการพัฒนาต่อ

ผู้ที่สนใจสามารถศึกษาโครงสร้าง Frontend, Backend, การเชื่อมต่อ API และการจัดการฐานข้อมูล MySQL ผ่าน phpMyAdmin ที่ใช้งานร่วมกับ Docker รวมถึงปรับปรุงฟังก์ชันและเพิ่มความปลอดภัยให้เหมาะสมกับการใช้งานจริง
